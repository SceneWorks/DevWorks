# Index

This optional semantic package analyzes TypeScript and JavaScript, including JSX, TSX and ES or CommonJS modules. The compiler resolves local calls, imports, packages and exports. It records React, Angular, service routes and Tauri relationships when the captured source supplies the evidence.

The macOS arm64 bundle needs Node 24. The bundle includes the compiler and its libraries. Install it through Add-ons, approve the exact manifest and select the package in the repository source configuration. The desktop can start and index structurally without Node or this package.

The package reads an exact commit or worktree capture and never evaluates repository scripts, application code or dependency code. It allows up to 4 MiB of input across 4,096 files and an 8 MiB result. The owned Node process has a 45-second deadline, a 1 GiB V8 old-generation heap limit and a sampled 2 GiB process-group memory limit. Compiler failures preserve structural coverage. Rebuild Index retries a retained failure.
