### DevWorks

DevWorks is a Rust-based platform for managing developer workflows, knowledge, and operations. It consists of a core domain library (`devworks-core`) that defines domain primitives, storage ports, gateway logic, and protocol types; a SQLite adapter layer (`devworks-adapters`) that implements those ports against a local SQLite database; a contract probe tool (`devworks-contract-probe`) that defines and validates the public JSON API contract types; and evaluation harnesses (`eval-*`) for benchmarking storage backends. The system tracks events, operations, queue deliveries, grants, configuration proposals, and package/addon lifecycle using an event-sourced, revision-controlled architecture.
