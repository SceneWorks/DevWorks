## Projects

### DevWorks

DevWorks is a Rust workspace that implements a developer tooling platform with authority/permission enforcement, filesystem safety, process management, HTTP transport, and SQLite-backed storage. The `devworks-adapters` crate provides concrete implementations (native filesystem, Unix process host, HTTP via ureq, SQLite via rusqlite) of port interfaces defined in `devworks-core`, while `devworks-contract-probe` and `eval-*` crates supply contract evaluation tooling and storage benchmark harnesses respectively. The project enforces safety invariants around destructive filesystem operations (protected roots, repository identity checks, TOCTOU guards) and manages an artifact/authority/configuration ledger persisted in SQLite.
