### DevWorks

DevWorks is a developer tooling platform built in Rust with a layered architecture: a core domain crate (devworks-core) defines abstract ports and authority/permission models, while devworks-adapters provides concrete implementations for filesystem operations, process management, and SQLite-backed storage. The project includes a contract-probe tool for evaluating extension/plugin package contracts and a storage evaluation harness for benchmarking graph/vector database adapters. The system enforces safety guarantees around destructive filesystem operations (protecting git repositories, worktrees, and app data roots), manages process lifecycle, and maintains an authority/permission ledger with grants and principal bindings.
