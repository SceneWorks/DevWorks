### DevWorks

DevWorks is a developer tooling platform built in Rust, organized as a multi-crate workspace. The `devworks-adapters` crate provides concrete implementations of platform ports (filesystem operations, HTTP transport, process management, and code indexing), while `devworks-core` defines the abstract interfaces and authority/permission models. The platform includes a plugin/package system (`devworks-contract-probe`) with a structured RPC contract for addon contributions, broker invocations, and provider bindings, as well as evaluation harnesses (`eval-*` crates) for benchmarking graph/vector storage backends.
