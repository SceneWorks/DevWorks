## Projects

### DevWorks

DevWorks is a developer tooling platform (not firmware) consisting of a core domain library (`devworks-core`), platform adapters (`devworks-adapters`), a SQLite-backed storage layer, and evaluation/contract tooling. The adapters crate provides native Unix implementations for safe filesystem operations (with protected-root enforcement, verified reads, and atomic deletion), process lifecycle management (spawn/probe/terminate via libc), and SQLite persistence for artifacts, authority grants, principal bindings, and configuration proposals. A separate `devworks-contract-probe` crate defines the serializable protocol structures for a package/contribution/provider host contract, while `eval-common` and related crates form a benchmarking and evaluation harness for graph/vector storage backends.
