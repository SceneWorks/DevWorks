## Projects

### DevWorks

DevWorks is a Rust-based developer tooling platform that combines a filesystem authority/safety layer (devworks-adapters), a SQLite-backed storage layer, and a contract evaluation framework (devworks-contract-probe). The adapters crate provides safe, permission-checked filesystem operations (destructive deletion, verified reads) against protected roots such as git repositories and worktrees, while the storage crate manages structured records (artifacts, grants, events, deliveries, authority principals) in SQLite. The contract-probe tool defines the domain protocol types (IDs, revisions, receipts, commands, queries) used for evaluating contracts against the system.
