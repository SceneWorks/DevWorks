### DevWorks

DevWorks is a multi-crate Rust workspace that implements infrastructure adapters for a developer tooling platform. The `devworks-adapters` crate provides concrete implementations of port interfaces defined in `devworks-core`, including: multi-database metadata readers (MySQL, PostgreSQL, SQL Server, SQLite) that introspect schema structure via SQL queries; a filesystem layer with security-enforcing verified reads and destructive operation controls (preflight checks, symlink validation, protected-root enforcement); an HTTP transport adapter; and code indexing extractors for SQL, Ansible, API endpoints, and Cargo manifests via tree-sitter parsing. The `devworks-contract-probe` crate defines serializable protocol types for an AI/LLM provider contract evaluation harness, while `eval-common` provides shared workload abstractions for storage backend benchmarking.
