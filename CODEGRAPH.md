### DevWorks

DevWorks is a Rust-based platform that orchestrates AI-assisted software development workflows. It consists of multiple crates: a core domain library (devworks-core) defining authority, destructive filesystem operations, and storage port traits; an adapters crate (devworks-adapters) providing SQLite storage and native filesystem implementations; a contract-probe crate (devworks-contract-probe) defining the data types and protocol contracts for domain commands/queries; and evaluation tooling (eval-*) for benchmarking storage and graph traversal backends. The system manages repositories, worktrees, grants/permissions, events, and agent sessions with safety-conscious filesystem operations protected by preflight checks.
