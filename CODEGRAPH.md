## Projects

### DevWorks

DevWorks is a multi-crate Rust monorepo implementing an AI-assisted developer tooling platform. The `devworks-adapters` crate provides concrete implementations (adapters) of abstract ports defined in `devworks-core`, covering database metadata introspection across MySQL, PostgreSQL, SQL Server, and SQLite; source code indexing via tree-sitter grammars for numerous languages; filesystem safety enforcement for destructive operations; process spawning and lifecycle management on Unix; HTTP streaming to AI provider endpoints; and pricing catalog parsing for LLM usage billing. Supporting tool crates (`devworks-contract-probe`, `eval-*`) provide contract testing and evaluation harnesses for the AI provider protocol and vector-search storage backends respectively.
