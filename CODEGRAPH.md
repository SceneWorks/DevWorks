### DevWorks

DevWorks is a multi-crate Rust monorepo implementing a developer tooling platform with infrastructure adapters, code indexing, AI provider integration, and database metadata introspection. The `devworks-adapters` crate provides concrete implementations (adapters) for ports defined in `devworks-core`, including database schema readers for MySQL, PostgreSQL, SQL Server, and SQLite; a filesystem authority system for safe destructive operations; a source code indexer using tree-sitter grammars for multiple languages; AI provider streaming HTTP transport; Unix process management; and AI pricing catalog parsing. Supporting tool crates (`devworks-contract-probe`, `eval-common`, etc.) handle contract evaluation for AI provider protocol compliance and vector search benchmarking.
