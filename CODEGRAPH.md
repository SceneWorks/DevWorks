### DevWorks

DevWorks is a multi-crate Rust monorepo that implements an AI-assisted developer tooling platform. The `devworks-adapters` crate provides infrastructure adapters for database metadata collection (MySQL, PostgreSQL, SQL Server, SQLite), source code indexing via tree-sitter parsing (Ansible, SQL, endpoint detection, manifest parsing for Cargo/SwiftPM), process management on Unix, and streaming HTTP communication with AI providers. The `devworks-contract-probe` and `eval-*` tools handle AI provider protocol conformance testing and vector-search/retrieval evaluation respectively.
