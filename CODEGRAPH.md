### DevWorks

DevWorks is a Rust-based developer tooling platform consisting of multiple crates: `devworks-adapters` provides concrete implementations (adapters) for browser detection, filesystem operations with safety guards, HTTP transport, code indexing (via tree-sitter for many languages), manifest parsing, and process management; `devworks-contract-probe` defines the wire protocol types for probing AI/LLM provider contracts; and evaluation harnesses (`eval-*`) benchmark various storage and graph backends. The adapters crate implements port interfaces defined in `devworks-core`, enforcing security policies such as protected-root filesystem checks and verified reads, while the indexing subsystem parses source code across many languages to extract structural information.
