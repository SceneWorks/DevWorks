### DevWorks

DevWorks is a multi-crate Rust monorepo that implements a developer tooling platform with capabilities spanning database metadata collection (MySQL, PostgreSQL, SQL Server, SQLite), filesystem operations with safety/authority enforcement, source code indexing (Ansible, SQL, API endpoints, package manifests), and an AI provider contract evaluation framework. The `devworks-adapters` crate provides concrete implementations of core port interfaces defined in `devworks-core`, connecting to real databases, filesystems, and parsers. Supporting tools include a contract probe for evaluating AI provider protocol conformance and a storage evaluation harness.
