### DevWorks

DevWorks is a developer tooling platform built as a Rust workspace with a layered architecture. The `devworks-adapters` crate provides concrete implementations (native filesystem, HTTP, process, browser detection, and code indexing) of abstract ports defined in `devworks-core`. A separate `devworks-contract-probe` tool evaluates AI provider contracts, while `eval-*` crates benchmark vector/graph storage backends. The adapters layer enforces security boundaries (protected filesystem roots, verified reads, destructive operation preflight checks) and parses source code across many languages for structural indexing.
