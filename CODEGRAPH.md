### DevWorks

DevWorks is a developer tooling platform built in Rust that provides a secure, authority-controlled environment for managing code repositories, processes, and file system operations. The project is structured into a core domain library (devworks-core), adapter implementations (devworks-adapters) for filesystem, HTTP, process management, and code indexing, and evaluation/contract testing tools. Key responsibilities include safe destructive filesystem operations with protected-root enforcement, multi-language code indexing via tree-sitter, process lifecycle management, and an AI provider contract protocol for LLM inference interactions.
