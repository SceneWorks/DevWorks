### DevWorks

DevWorks is a developer tooling platform built in Rust with a layered architecture: a core domain crate (devworks-core) defining ports/traits, an adapters crate (devworks-adapters) providing native OS implementations for filesystem operations, process management, and SQLite-backed storage, and tooling crates for contract evaluation and storage benchmarking. The adapters crate implements destructive filesystem operations (tree removal, unlinking) with a preflight/authority safety system that protects Git repositories and registered worktrees from accidental deletion, as well as verified file reads, Unix process lifecycle management, and SQLite persistence for artifacts, authority grants, configuration proposals, and principal bindings.
