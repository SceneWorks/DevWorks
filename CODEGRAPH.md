## Projects

### DevWorks

DevWorks is a Rust-based application platform with a domain-driven architecture, consisting of a core domain logic crate (`devworks-core`), a storage adapter crate (`devworks-adapters`), and a contract evaluation tool (`devworks-contract-probe`). The core provides a command/event gateway pattern with admission control, idempotency via receipts, revision-conflict detection, and a grant/ledger system for authorization. The SQLite adapter implements persistent storage for events, operations, queue entries, and grants, while the contract-probe tool defines and validates the external protocol schema (data types, commands, queries) used across the system.
