### DevWorks

DevWorks is a developer tooling platform built in Rust, organized as a multi-crate workspace. The `devworks-adapters` crate provides concrete implementations of system-level abstractions defined in `devworks-core`, including a safety-guarded filesystem layer with protected-root enforcement and verified reads, a process management layer for spawning/probing/terminating Unix processes, an HTTP transport adapter, and a code indexing subsystem that extracts structural information from source files using tree-sitter grammars for numerous languages and package manifest formats (Cargo, SwiftPM). The `devworks-contract-probe` crate defines serializable data types for interacting with AI inference providers, while evaluation tool crates (`eval-*`) benchmark various storage and graph backends.
