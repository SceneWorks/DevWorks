### DevWorks

DevWorks is a multi-crate Rust monorepo implementing a developer tooling platform with AI/LLM provider integration, code indexing, filesystem safety enforcement, HTTP transport, and SQLite-backed storage. The `devworks-adapters` crate provides concrete implementations of ports defined in `devworks-core`, including a safety-audited native filesystem adapter with pre-flight checks and destructive-operation guards, a tree-sitter-based structural code parser supporting many languages, manifest extractors for Cargo/SwiftPM, an HTTP transport layer, and SQLite adapters for artifacts and authority grants. Additional tool crates (`devworks-contract-probe`, eval harnesses) support LLM provider contract evaluation and storage benchmarking.
