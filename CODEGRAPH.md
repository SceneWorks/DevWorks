### DevWorks

DevWorks is a multi-crate Rust monorepo implementing a developer tooling platform. The `devworks-adapters` crate provides concrete adapter implementations for the platform's port interfaces, covering database metadata extraction (MySQL, PostgreSQL, SQL Server, SQLite), source code indexing via tree-sitter (across 20+ languages), filesystem destructive-operation safety checks, process spawning/termination on Unix, HTTP streaming to AI providers, and AI pricing catalog parsing. Supporting tool crates (`devworks-contract-probe`, eval harnesses) provide contract definitions and evaluation workloads for the platform's AI provider and vector-search subsystems.
