### DevWorks

DevWorks is a multi-crate Rust repository implementing a developer tooling platform with adapters for database metadata reading (MySQL, PostgreSQL, SQL Server, SQLite), code indexing via tree-sitter (across 20+ languages including Rust, Go, Python, Swift, etc.), process management, HTTP streaming to AI providers, filesystem safety enforcement, and AI pricing catalog parsing. The `devworks-adapters` crate provides concrete implementations (adapters) of ports defined in `devworks-core`, while `devworks-contract-probe` defines serializable protocol types for inference/provider interactions, and evaluation crates (`eval-*`) provide workload benchmarking infrastructure.
