### DevWorks

DevWorks is a Rust-based developer tooling platform structured as a multi-crate workspace. The `devworks-adapters` crate provides concrete implementations of platform-abstraction ports defined in `devworks-core`, including native filesystem operations (with safety/authority checks for destructive actions), HTTP transport via ureq, browser executable discovery, process lifecycle probing, and structural code indexing via tree-sitter across many languages. Additional tool crates (`devworks-contract-probe`, `eval-*`) handle AI provider contract evaluation and vector-search workload benchmarking respectively.
