### DevWorks

DevWorks is a developer tooling platform with a layered architecture consisting of a core domain library (devworks-core), platform adapters (devworks-adapters), and evaluation/contract tooling. The adapters crate provides concrete Unix filesystem operations (safe destructive execution with protected roots, verified reads, symlink resolution), process lifecycle management (spawn/probe/terminate via libc), and SQLite-backed persistence for artifacts, authority grants, configuration proposals, and repositories. The contract-probe and eval tools provide schema definitions and benchmarking harnesses for the plugin/package system and graph storage backends.
