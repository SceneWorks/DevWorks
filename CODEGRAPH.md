### DevWorks

DevWorks is a Rust workspace containing an infrastructure/developer-tooling platform with multiple crates. The `devworks-adapters` crate provides concrete implementations (adapters) of abstract port interfaces defined in `devworks-core`, covering database metadata reading (MySQL, PostgreSQL, SQL Server, SQLite), filesystem operations with safety/authority enforcement, HTTP transport, and code indexing (Ansible, SQL, endpoint extraction, Cargo manifests). Supporting tools include `devworks-contract-probe` for probing AI provider contracts and `eval-common` for storage/retrieval evaluation workloads.
