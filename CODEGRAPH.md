## Projects

### DevWorks

DevWorks is a Rust-based developer tooling platform consisting of multiple crates: a core domain model (devworks-core), platform adapters (devworks-adapters), contract evaluation tools (devworks-contract-probe), and storage evaluation benchmarks (eval-*). The devworks-adapters crate provides Unix-specific implementations of filesystem operations (safe destructive operations with protected-root enforcement, verified reads, symlink resolution), process management (spawn/probe/terminate via libc), and SQLite-backed storage for artifacts, authority grants, principal bindings, and configuration proposals. The contract-probe tooling defines serializable message types for a package/contribution lifecycle protocol, while the eval-* tooling benchmarks graph database adapters.
