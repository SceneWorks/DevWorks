### DevWorks

DevWorks is a multi-crate Rust workspace that implements a developer tooling platform with capabilities spanning safe filesystem operations, code indexing, HTTP transport, SQLite-backed storage, and an AI provider contract evaluation harness. The `devworks-adapters` crate provides concrete implementations of core port traits (filesystem authority/safety, HTTP, indexing extractors for many languages, and SQLite persistence), while `devworks-contract-probe` and `eval-*` crates supply contract testing and benchmarking infrastructure for inference/embedding providers and graph-based retrieval backends.
