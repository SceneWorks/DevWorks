### DevWorks

DevWorks is a Rust workspace that implements a developer tooling platform with AI/LLM provider integration, package management, authority/permission management, and filesystem safety primitives. The project consists of a core domain library (devworks-core), a platform adapter layer (devworks-adapters) providing SQLite storage and Unix filesystem implementations, a contract probe library (devworks-contract-probe) defining the public protocol types for package/provider communication, and evaluation tooling for storage and vector-search backends. The adapter layer enforces safety invariants such as protected filesystem roots, verified reads, and destructive operation preflight checks before executing removals.
