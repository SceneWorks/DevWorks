Routine runtime/recovery decisions are adopted under the user’s delegated architectural discretion; remaining proposals and validation gates stay explicit. No native application has been implemented.

The proposal defines component boundaries, domain identities, storage authority, durable effects/recovery, agent and router contracts, native UI context, delivery gates, indexing, Knowledge/RAG, executable extensions, lifecycle, documentation, and testing. Its decision register and validation gates distinguish recommended designs from demonstrated behavior. Diagram relationships are conceptual views, not physical database schemas.

Runtime refinement now specifies activation ownership, eligibility/resume authority, parallel tool turns, approval wakeups, redirects and shutdown/recovery, with acceptance scenarios. Persistence now specifies repository/transaction contracts, an initial SQL schema and indexes, fenced queue claims, overlay publication, immutable files, migration compatibility, manual backup/restore and logical export. Document versions are retained until explicit deletion; restored automation requires reactivation. Router refinement now defines typed requests, native provider streams, credential lifecycle, durable pins/cooldowns, effect-aware failover, cache/context epochs and attributed usage. Official prices refresh weekly while open; local-free, custom-untracked and subscription estimate policies are explicit. Executable package refinement now defines the protocol/SDK boundary, all contribution categories, scoped broker calls, cancellation, trusted signed updates, atomic registry/state publication and guarded rollback. Security refinement specifies the Full default, workspace/project authority, verified reads, revocation, stable-target deletion safeguards, dedicated user confirmation and native credentials. The OS/CPU/display matrix and confined-execution candidates are explicit qualification targets. Retained capability accounting now binds the frozen CodeGraph surface to native operations and 33 behavioral acceptance groups; legacy Shortcut/RabbitMQ integrations are explicitly excluded. Twelve representative workload specifications and provisional engineering budgets precede actual native measurement. Tokio channels handle live dispatch while atomic SQLite events/deliveries own recovery. Initial Word support is modern .docx only. Scheduled inference reports usage without job spending limits; feature-owned work retains feature budgets. Stable app releases with explicit prerelease opt-in, exact install/restart approval and separate configurable clone/worktree/data roots are specified. The carried product choices are resolved. A complete local ownership/dependency breakdown now exists; operation schemas are now concrete; actual contract adoption and targeted dependency qualification remain explicit admission gates. Requirements and planning stay in local files; do not create Shortcut records. Unit/integration tests must use no real inference; the live end-to-end suite is separate later work.
