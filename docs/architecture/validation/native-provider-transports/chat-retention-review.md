# Chat envelope retention review

The additional-choice loop copied the full Chat aggregate or SSE envelope for every unsupported choice. The same concrete pattern existed for unsupported content-array parts and non-function tool calls in the primary choice. All three loops now retain one original envelope and exact raw slices for each nested observation. Provider order, numeric/escaped lexemes, unsupported status and refusal to release tools are preserved; decoding limits are unchanged.

The bounded causal test on the original source failed at 64 choices: 6,320 input bytes allocated 935,827 bytes. The same fixed input allocates 546,727 bytes. Full 5,000-choice aggregate and SSE inputs pass for both CompatibleChat and OpenRouterChat; aggregate 498,948 bytes allocates 40,559,623 bytes with 27,288,133 additional live bytes at peak. A separate bounded content-array RED confirms the sibling path. GREEN covers 2,000 unsupported content and tool items, preserving every exact item and one envelope. The original 5,000-choice multiplication was not executed.

Four allocation/retention tests, 26 pure decoder tests, 42 actual provider integration regressions, and affected core/adapters/engine all-target strict lint pass. Tests include escaped and duplicate structural keys, an opaque out-of-range numeric lexeme, exact usage integers, aggregate/SSE, and no dispatchable tools on unsupported responses. All 67 existing schema artifacts, including 56 legacy schemas, are byte-identical to d784. Results, source/binary hashes and native commands are in chat-retention-results.json.

The related-loop audit covers all seven profiles. Existing Responses folding and d784 Messages aggregation already borrow arrays and exact nested slices once; standalone native events contain one item/block. Embedding retains one response and emits vectors per row. Usage lookup uses a finite set of field paths. No further concrete enclosing-envelope population loop was found. This is a bounded regression and source audit, not a universal parser-performance claim. No network or inference compute ran.
