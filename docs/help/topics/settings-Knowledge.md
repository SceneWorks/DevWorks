# Documents and retrieval settings

Vision extraction fallback defaults on, but actual extraction first needs a supported document reader and a qualified routed vision producer. Offline lexical retrieval does not need a model. The lesson recurrence threshold defaults to three distinct source events and inherits Workspace then Project; direct user-origin lessons take effect immediately. An inferred rule taking effect by recurrence is not a separate approval workflow.

## Apply a change

Choose the intended scope, read the effective value/source, edit, validate, and save or propose through the app. Keep the original draft and operation identity if the result is uncertain. For a revision conflict, refresh and explicitly review/rebase before retrying. Adoption timing and harness-enforced restrictions are listed in the [Complete settings reference](help:settings-reference).
