# Agent tools, web search, and page fetching

Web search and fetching are separate workspace tool controls. A provider must be configured for search; fetched pages remain untrusted artifacts. Timeouts, redirect bounds and private-network policy are explicit. The native fetch path validates destinations and redirects; it must not forward credentials to another origin. Turning a tool on does not install an adapter or grant a reviewer mutation rights.

## Apply a change

Choose the intended scope, read the effective value/source, edit, validate, and save or propose through the app. Keep the original draft and operation identity if the result is uncertain. For a revision conflict, refresh and explicitly review/rebase before retrying. Adoption timing and harness-enforced restrictions are listed in the [Complete settings reference](help:settings-reference).
