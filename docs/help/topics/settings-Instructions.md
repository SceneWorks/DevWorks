# Role instructions and adoption

Workspace coordinator, feature coordinator, issue coordinator, worker, code reviewer, Dreaming and scheduled roles each have editable instruction text. Project overrides can inherit from workspace. Agent-drafted edits need the appropriate human decision and adopt at the next safe step. Instructions cannot grant tools, override an actual human direction, remove reviewer read-only enforcement, or bypass root controls. Continuing existing work retains history rather than starting a new identity.

## Apply a change

Choose the intended scope, read the effective value/source, edit, validate, and save or propose through the app. Keep the original draft and operation identity if the result is uncertain. For a revision conflict, refresh and explicitly review/rebase before retrying. Adoption timing and harness-enforced restrictions are listed in the [Complete settings reference](help:settings-reference).

See [Settings overview](help:settings), [Permissions](help:permissions), and [Recovery](help:recovery).
